# QuickBill - 免费在线发票生成器

> 100% 免费 | 无需注册 | 数据不上传服务器 | 一键导出PDF

**在线使用：[tyr1105.github.io/quickbill](https://tyr1105.github.io/quickbill/)**

## 功能特性

- 5种专业模板 - 现代简约、经典商务、优雅绿意、暖色活力、紫调高端
- 15种币种 - 人民币、美元、欧元、英镑、日元、港币等
- Logo上传 - 支持上传公司Logo
- 智能计算 - 自动计算小计、折扣、税额、合计
- PDF导出 - 一键导出高清PDF文件
- 本地存储 - 保存历史发票，随时调用
- 隐私安全 - 所有数据浏览器本地处理
- 完全免费 - 无限制、无水印

## 技术栈

React 19 + Vite + Tailwind CSS 4 + jsPDF
